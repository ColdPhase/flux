## Explicit limits

The outline is a personal browser preference, not shared or historical graph
hierarchy. Fresh/missing/corrupt/unavailable storage conservatively starts current
thoughts as roots. Existing graphs can be nested deliberately over currently
authorized links using **Group in list…**; its undo is separate from persisted
graph undo. Bounded ID-only intent is retained for graph deletion/undo, while
missing parents or connecting links detach the current branch. Quota failure
retains this visit's useful grouping but cannot promise persistence on reload.
