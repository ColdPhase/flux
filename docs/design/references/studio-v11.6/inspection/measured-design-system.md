# Flux Studio 11.6 — measured design-system specification

Source: `docs/design/references/studio-v11.6/supplied/flux-studio-v11.6.html` (sha256 `5c0f26dd…f943e7`, runtime `Flux.release` 11.6 / co-op 11.6).
Method: unchanged copy served on container loopback, Playwright 1.62 / Chromium 151.0.7922.34 in `mcr.microsoft.com/playwright/python:v1.62.0-noble`, `--network none`, DPR 1, fixed clock 2026-09-30T12:00Z, a fresh browser context per scenario. All values are **computed styles** (the last matching layer wins), not CSS text. Raw data `measured.json` (`tokens`, `accents`, `desktop.{light,dark}.<section>.<element>`, `phone`, `widths`, `media`, `motion`) and screenshots are regenerated by the [measuring scripts](../tools/measure/README.md); they are not checked in.
Viewport 1440×900 unless stated. Geometry is identical in light and dark; only colours differ (checked element by element). Light uses the demo user's default light accent **Sky**, dark the default dark accent **Mint** (the prototype remembers one accent per theme: `accents:{dark:'mint',light:'sky'}`). The demo user starts in dark.

Limits: Segoe UI / -apple-system / Roboto / Inter are not installed in the container, so text renders in the Arial-metric fallback. Declared sizes, weights and line-heights are exact; text **widths** are approximate. Borders declared 1.5px compute to 1px at DPR 1.

## 1. Global

**Font**: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif` for everything. The 11.4 serif `--title-font` is redefined to the UI font in 11.5, so there is no serif anywhere. Monospace: `ui-monospace, SFMono-Regular, Consolas, monospace` (wiki code), `monospace` (kbd). No Inter.
**Root**: 14px / 1.55 (21.7px), `font-synthesis:none`. `body` background `--chrome`, colour `--text`. Headings get `letter-spacing:-.025em` (≈ −0.5 to −0.75px).
**Scale actually in use**: 9 · 10 · 10.5 · 11 · 11.5 · 12 · 13 · 14 (reading) · 18 (phone title) · 20 · 21 (project title) · 24 · 30 (wiki title). Weights: 400 · 450 · 500 · 550 · 600 · 650. UI chrome is 11–12px; reading text 14px.

Accent is used only for selection and pointers: active nav bar, tab underline, focus ring, unread dot, wordmark dot, links/inline refs, focused borders, "doing" status ring, card hover border. It is **not** the primary button colour (that is `--action`).
