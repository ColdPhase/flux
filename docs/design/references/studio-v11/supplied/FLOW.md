# Flux Studio 11 — spójny przepływ

## Powrót

Wchodzisz do projektu. Zapisana poprzednia wizyta określa zakres nieobecności. Mały przycisk Co ważne otwiera prywatny panel. Cały projekt obejmuje również rozmowy niewskazujące Ciebie; Dotyczy mnie zawęża zakres. Podsumowanie zostaje tylko w Twoim widoku. Materiały źródłowe można otworzyć i wrócić stałym przyciskiem. „Mam kontekst” nie czyści czatu ani nie kończy pracy.

## Rozmowa → mapa

Piszesz bez tematu. Wypowiedź można rozwinąć na mapie. Myśl zachowuje źródło, ale jej tekst można zmieniać bez poprawiania historii autora. Plus dopisuje nową gałąź. „Do rozmowy” z dziecka wskazuje dziecko; opublikowanie wymaga wysłania przygotowanej karty.

## Mapa → działanie

Dwie myśli mogą wskazywać jedno podjęte zadanie. Mapa nie przyjmuje statusów kanbanu. Lista pokazuje gałęzie i boczne związki bez kopii myśli. Wyszukiwarka otwiera dokładny element, również z innej mapy projektu.

## Zadanie → przeszkoda → rozwiązanie

Tytuł wystarcza. Nakład w dniach nie jest terminem. Osobisty plan nie jest wspólnym zobowiązaniem. Jedna wypowiedź oznaczona jako przeszkoda jest powodem blokady i prośbą o pomoc. Rozwiązanie tej konkretnej przeszkody nie kończy zadania i nie usuwa innych.

## Razem

Przy materiale uruchamiasz sesję bez dzwonienia. Dołączenie nie włącza urządzeń. Pokaż fragment to natywne obiekty; Ekran jest świadomym przechwytywaniem. Podążanie wymaga zgody i kończy się przy własnej nawigacji. Cisza zachowuje obecność, wyjście zatrzymuje urządzenia. W HTML inni uczestnicy i transmisja są symulowani.

## Wynik → wiedza

Wynik jest wskazaną wiadomością. Zadanie i mapa odczytują ją bez tworzenia kopii. Agent regułowy może przygotować dopisanie obserwacji do jednoznacznie wskazanej wiki. Propozycja nie jest decyzją; zastosowanie wymaga aktualnych źródeł. Użytkownik pozostaje autorem swojej wypowiedzi, agent ma osobny podpis.

## Cel

Po rzeczywistym sprawdzeniu rezultatu potwierdzacie cel. Same zakończone taski go nie potwierdzają. Następny cel zachowuje poprzedni kierunek. Może też nie być celu, gdy projekt jest jeszcze swobodnym szkicem.

## Przeniesienie projektu

Eksport projektu zawiera materiały, autorstwo i zapisaną historię, lecz nie prywatny skrót ani notatki osób. Import tworzy nową kopię z przepiętymi odnośnikami, historią autorów i wyłączonymi automatami. Nie scala kont ani nie publikuje danych innego projektu.

## Brak przymusowej kolejności

Można zacząć od wiki, zwykłej rozmowy lub jednego taska. Nie trzeba odwiedzić wszystkich czterech widoków. Spójne są źródła i skutki, nie liczba ani treść obiektów.
