# O-003 rendered evidence (#15, AC-2 and AC-3)

Generated by `tools/audit.py` in Docker (`mcr.microsoft.com/playwright/python:v1.62.0-noble`, Chromium) on the two static prototypes. Raw output: `audit.json`. Reproduce from the repository root:

```sh
docker run --rm -v "$PWD/docs/design/proposals/o-003-ui-direction:/work" -w /work \
  mcr.microsoft.com/playwright/python:v1.62.0-noble python3 tools/audit.py
```

Viewports are CSS px at 100% zoom: 1440×900, 1280×800, 1024×768 and 768×1024 (tablet, touch), 390×844 and 360×780 (phone, touch). Screens up to 1024 px wide are emulated with a coarse pointer, as on the real devices.

| Check | A: return ledger | B: state board |
| --- | --- | --- |
| Horizontal overflow, all viewports | none | none |
| Console errors | 0 | 0 |
| Visible text below 12 px | 0 | 0 |
| Text contrast below WCAG 2.2 AA (4.5:1, or 3:1 for large text) | 0 | 0 |
| Touch targets on tablet or phone below 44 px (24 px for inline references in sentences, per the WCAG 2.5.8 inline exception) | 0 | 0 |
| 200% zoom (a 1440×900 window lays out as 720×450) | no overflow | no overflow |
| Software keyboard (390×480 with the composer focused) | composer visible | composer visible |
| Keyboard: first 40 Tab stops at 1440×900 without a visible focus ring | 0 | 0 |
| `prefers-reduced-motion: reduce`: animated elements | 0 | 0 |

**What these checks do not cover:**
- Contrast of non-text elements (borders and icons) is not computed.
- A screen reader was not run.
- Real iOS/Android keyboards and safe areas are emulated, not tested on devices. Those checks belong to #20.
- The prototypes are static. They prove layout and basic keyboard behavior only, not the product behavior of persistence, permissions or agents.
