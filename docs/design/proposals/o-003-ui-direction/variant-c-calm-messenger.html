Current rule · accepted Sep 22

Exclude items guests can't open

CSV and XLSX exports leave out every item the recipient can't open. The check runs when the file is generated, so items archived after an export was scheduled are covered too.

Why it changed

Cost: about 9 s more per 40k-row export. Acceptable, since scheduled exports run overnight.
