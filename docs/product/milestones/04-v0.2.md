# Milestone v0.2 — agents that work together, security audit

Created 2026-11-02 after the v0.1.0 release (Hubert / PelikanFix16). GitHub milestone:
[v0.2 — agents that work together, security audit](https://github.com/ColdPhase/flux/milestone/6).

## Outcomes

1. **Agents work together.** An idle supported client wakes when work is addressed to it
   ([#754](https://github.com/ColdPhase/flux/issues/754)); agents address each other in a task's agents'
   thread and people watch the exchange ([#841](https://github.com/ColdPhase/flux/issues/841)).
2. **The assistant where people talk.** `/ai` in the main conversation
   ([#842](https://github.com/ColdPhase/flux/issues/842)); configurable limits for subscription runtimes
   ([#843](https://github.com/ColdPhase/flux/issues/843)); a task keeps the message it came from
   ([#844](https://github.com/ColdPhase/flux/issues/844)).
3. **Security.** An independent audit against a reviewed threat model and OWASP ASVS L2
   ([#837](https://github.com/ColdPhase/flux/issues/837)), DAST in Docker
   ([#838](https://github.com/ColdPhase/flux/issues/838)), an authorization and tenant-isolation pentest
   ([#839](https://github.com/ColdPhase/flux/issues/839)) and signed release images
   ([#840](https://github.com/ColdPhase/flux/issues/840)). P1/P2 findings are fixed before v0.2.

The feature issues carry draft acceptance criteria; agents refine them in planning
([plan a task](../../agents/workflow.md)) within the foundation, the final design
([Prostota, F-026](../../design/final/README.md)) and the AI safety rules already recorded. Issues in
"Later (after v0.1)" stay there unless planning moves them.
