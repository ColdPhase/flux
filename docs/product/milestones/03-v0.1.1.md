# Milestone v0.1.1 — arm64 and security scanning

Created 2026-11-02 after the v0.1.0 release (Hubert / PelikanFix16). GitHub milestone:
[v0.1.1 — arm64 and security scanning](https://github.com/ColdPhase/flux/milestone/5).

A patch release. No new product features.

- **arm64** ([#833](https://github.com/ColdPhase/flux/issues/833)): v0.1.0 shipped `linux/amd64` only
  (decision on [#249](https://github.com/ColdPhase/flux/issues/249)); v0.1.1 publishes `linux/arm64` too.
- **Security scanning in CI**: dependency updates and advisories ([#834](https://github.com/ColdPhase/flux/issues/834)),
  release image scanning ([#835](https://github.com/ColdPhase/flux/issues/835)), CodeQL/SAST
  ([#836](https://github.com/ColdPhase/flux/issues/836)). Keep PR Actions light; heavy scans run on the
  release pipeline or on a schedule.
- **Performance follow-ups** from the v0.1.0 independent review: [#827](https://github.com/ColdPhase/flux/issues/827),
  [#828](https://github.com/ColdPhase/flux/issues/828).

Release: the same acceptance runner and independent review as v0.1.0
([evaluation](../../agents/evaluation.md), [CI and releases](../../agents/ci-and-releases.md)), with arm64
added to the packaged-install smoke.
