## Handoff

Post once, short, when the PR is ready for review or when you release ownership.

- Issue / PR:
- Branch and pushed head SHA:
- Evaluator (@mention) or next owner:
- Criteria done / remaining (by `AC-*` ID):
- Checks run and results (unavailable checks stated explicitly):
- Next action, or the blocker and its unblock condition:

Mention any unpushed or uncommitted work and where it is; the peer cannot recover
work that exists only on one machine. Keep secrets and machine-private data out.
