## Criterion matrix

**States.** `done`: the behavior is merged on `main` with reproducible checks (named tests or
scripts); rows that cite a run link its log at a named commit. It still needs its run and an
independent verdict at the frozen candidate.
`open`: in-repository work remains (PR or issue named). `external`: only a person, a device,
a credential or a public service can supply what remains ("needs Maurycy"). `excluded`: out
of scope by a recorded decision. A row with both open and external parts is `open`.
