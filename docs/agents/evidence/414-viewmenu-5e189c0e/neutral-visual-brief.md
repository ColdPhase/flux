# Neutral visual brief — Flux phone project menu

Assess whether the project title and its menu are easy to find and understand, whether the menu is legible and balanced at both narrow widths and in both themes, and whether the surrounding task surface remains useful. Compare the screenshots with the accepted F-026 phone references. Report only visible hierarchy, clarity, density, or character issues; separate those from personal preference.
