# Neutral visual brief — Flux Wiki phone slice

Source revision: `6b344acedd1479e5f4e1ffcc03accd85937f6754`.

These frames were rendered in Chromium by the repository's `scripts/check_ui.sh` runner. They come from two fixtures, recorded separately in `manifest.json`: Ada Kowalska’s restricted “Community garden sensors” project with five published pages, and the “Arduino + AI” project shared by Hubert Lis, Marek Wolny and Noa Berg, with Wiki pages, import drafts and the long “How the lamp works” article. Do not treat these as one fixture or one state.

Please assess the supplied frames against F-026 §4 Phone and the Wiki guidance in `docs/design/final/README.md`, using `docs/design/final/screens/phone-wiki.webp` as the primary phone reference and `desktop-wiki.webp` for the desktop import frames. Relevant visible constraints include a compact project title/view menu with people and Wiki context, a Wiki page chip row without an extra toolbar, the page content following the chips, readable content on narrow screens, and reachable page actions. The opened menu should clearly show project views and its Details entry. The phone reading/edit frames include the long article and its editor. The phone page-state frame shows the “Retried import” draft. Desktop frames show the “Power budget” import-success state and the refused broken Markdown import. No wide-table screenshot is included in this packet.

Please report visible hierarchy, density, clipping, contrast, and reference alignment only. These screenshots do not establish interaction behavior or accessibility.
