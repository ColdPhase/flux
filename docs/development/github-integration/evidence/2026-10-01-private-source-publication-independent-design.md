Define the projection's native-status mapping, separate execution state, visible timestamp/ETag tuple, and exact command packet/version behavior. A revocation path can skip unused native locks but cannot later acquire one in reverse order. Recheck provenance/versions under the selected locks; server cancellation must drain rollback.
