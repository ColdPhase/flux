- Search finds every file by its name, of any kind: a photo, a video, a recording, a spreadsheet, so "IMG_2041" finds IMG_2041.jpg, in people's search and in an agent's `flux_search` alike. What a file says is still read only for a PDF, DOCX, Markdown, text, CSV and TSV file. In an encrypted space the name is found while the space is unlocked, and what its files say is never read ([#1424](https://github.com/ColdPhase/flux/issues/1424) decision B).
