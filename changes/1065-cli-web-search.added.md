- Agents on your own Claude Code (a Claude plan in Connect AI) search the web with Claude Code's own search, on by default like the search of agents on an API key. Each search is recorded with the run, its results are the only new addresses the agent may open with Flux's page reading, and the answer lists what it searched and the pages it named. Codex has no search yet: its events do not carry the results ([#1065](https://github.com/ColdPhase/flux/issues/1065)).
