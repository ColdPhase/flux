- `./flux up` asks once, on its first interactive run, whether people on this Flux may sign in with their own ChatGPT and Claude subscriptions, and the new `./flux ai on` asks the same on an existing instance. Enter means yes (Codex); Claude Code needs a typed `y` to Anthropic's Commercial Terms, which writes today's date as your statement. Hosts whose Docker engine cannot run the agent runtime (no Yama `ptrace_scope`, no internal networks, no limits, Docker Desktop) are not asked and get one line saying why; without a terminal nothing is asked or written ([#494](https://github.com/ColdPhase/flux/pull/494)).
