- Moving between places asks the server less: the project, its people, the members, the space's docs and the agents' unread dots are kept for a moment, and what waits for you is read once per page, so the next view shows them without asking again. Anything that could change them (a change you make, a live update, signing out) forgets them, and a refresh on focus still reads. Going from Home to the Inbox now costs two requests instead of four, and entering a space 14 instead of 20 ([#862](https://github.com/ColdPhase/flux/issues/862)).
