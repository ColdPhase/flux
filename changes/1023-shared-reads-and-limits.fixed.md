- A re-read that a live event causes (a space renamed in another tab, a grant taken away) can no longer join a read that began before the change and keep the old answer. The first sign-in page after a start no longer waits for a probe of the identity provider. A made-up session cookie no longer gets a request budget of its own: until the server has accepted a cookie, every request with it is charged to the address ([#1023](https://github.com/ColdPhase/flux/issues/1023), [#1022](https://github.com/ColdPhase/flux/issues/1022)).
