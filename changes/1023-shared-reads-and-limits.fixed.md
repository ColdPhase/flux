- A re-read that a live event causes (a space renamed in another tab, a grant taken away) can no longer join a read that began before the change and keep the old answer. The first sign-in page after a start no longer waits for a probe of the identity provider. A made-up session cookie no longer gets a request budget of its own: a session cookie or an `/mcp` bearer has one only once the server has accepted it, it is the cookie Better Auth reads (not a decoy, a bearer or a space next to it), and a 401 takes it away; an IPv6 client counts as its /64 in the per-address limits ([#1023](https://github.com/ColdPhase/flux/issues/1023), [#1022](https://github.com/ColdPhase/flux/issues/1022), [#1040](https://github.com/ColdPhase/flux/issues/1040)).
