- Link cards show the linked page's own title and description in three lines instead of the address. The Flux server fetches the page, only when the operator sets `FLUX_LINK_PREVIEWS=on` (off by default): public `http`/`https` addresses on the default ports only, redirects re-checked, 3 s and 256 KiB limits, cached in memory, rate limited per person, and never for an encrypted workspace. No image is fetched ([#469](https://github.com/ColdPhase/flux/issues/469)).
