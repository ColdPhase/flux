- iPhone and iPad notifications work on a server at an https address without a setting: the contact Flux gives the push services (`FLUX_VAPID_SUBJECT`) is optional and, left empty, is the public https address (`FLUX_PUBLIC_ORIGIN`), which Apple accepts. `./flux up` no longer writes the placeholder Apple refused, a `docker/.env` from v0.2.0 that holds it counts as empty, and when a push service still refuses the contact the worker's log says so and what to set ([#1471](https://github.com/ColdPhase/flux/issues/1471)).
