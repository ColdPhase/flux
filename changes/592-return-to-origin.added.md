- Following a reference (a wiki card, a source message, a search result, an Inbox item, a person, an agent link) now shows one quiet "‹ Conversation", "‹ Search" or "‹ Inbox" control where you land, in the header row and in place of the phone's back (an object opened inside the panel keeps the panel's own "‹ Task #12" / "‹ Thread" step). Going back by it, browser Back, Alt+← or the phone's back gesture returns to the same page, filters, open thread or panel, reading position (also when new messages arrived) and unsent draft. Following a reference adds one history entry; panels and threads keep opening and closing in place. A place you have lost access to has no control, and Back lands on the nearest place that opens, with one short line ([#592](https://github.com/ColdPhase/flux/issues/592)).
