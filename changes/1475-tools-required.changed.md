- Only a model that calls tools can be an agent. When a key is added or a model is chosen for an agent, Flux sends the provider one small request with a `ping` tool the model must call; a model that does not is refused with "This model can't use tools. Choose another." and the key stays in its field for another model. There is no table of models and no owner's switch ([#1441](https://github.com/ColdPhase/flux/issues/1441), [#1475](https://github.com/ColdPhase/flux/issues/1475)).
