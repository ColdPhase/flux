- `FLUX_CALLS_PUBLIC_IP` for calls behind split-horizon DNS or a proxy on another machine: the public IPv4 address browsers send media to is kept, checked only for being IPv4 and never looked up, and `FLUX_LIVEKIT_DOMAIN` set in `docker/.env` is now the media name instead of being overwritten with the origin's host. Left empty, the lookup runs as before ([#1542](https://github.com/ColdPhase/flux/issues/1542)).
