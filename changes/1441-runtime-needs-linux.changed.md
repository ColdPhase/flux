- Flux AI needs a Linux host with kernel 6.7 or later (the agent runtime's sandbox needs Landlock ABI 4) and `kernel.yama.ptrace_scope` of 1 or higher. Where the host cannot run the runtime, `./flux up` keeps AI off and prints one line saying why: "Flux AI needs a newer Linux (kernel 6.7 or later, e.g. Ubuntu 24.04 or Debian 13).", or, for `ptrace_scope` 0, the fix (`sudo sysctl -w kernel.yama.ptrace_scope=1` and `echo 'kernel.yama.ptrace_scope = 1' | sudo tee /etc/sysctl.d/90-flux.conf` to keep it); owners and admins read the same line in Settings › AI. Docker Desktop on a Mac has no Yama, so AI stays off there ([#1441](https://github.com/ColdPhase/flux/issues/1441), [#1468](https://github.com/ColdPhase/flux/issues/1468)).
