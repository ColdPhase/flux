- A dynamic security test: `./scripts/check_dast.sh` runs OWASP ZAP against the running application in Docker, a baseline scan of the web app and an active scan of the API signed in as the owner and as a member, and lists what is left to triage; recorded false positives carry their reason. A manual step before a release ([#838](https://github.com/ColdPhase/flux/issues/838)). The API now has a floor of rate limits under every route (1,200 requests a minute per session, 600 per address without one; a read that gets a 429 waits and asks again with a calm "Flux is busy" line), and every response carries `X-Content-Type-Options`, `Permissions-Policy` and `Cross-Origin-Resource-Policy` ([#956](https://github.com/ColdPhase/flux/issues/956)).
