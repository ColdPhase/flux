- An instance installed from any release since v0.2.0 upgrades to any later release, by `./flux upgrade` or by the release's upgrade steps, and every release proves it before it is drafted: each earlier release is installed from its own assets, filled with people, spaces, an encrypted space, conversations, files, a wiki, maps, tasks, notification settings, a second device and an agent with memory and schedules, upgraded and read back, and the release notes name the versions it upgrades from. Released migrations never change. `./flux upgrade` carries a renamed setting of `docker/.env` over with a printed note and names a removed one, never ignoring it silently ([#1241](https://github.com/ColdPhase/flux/issues/1241)).
