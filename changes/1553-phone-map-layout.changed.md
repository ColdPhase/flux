- On a phone a map looks as it does on the computer: each thought stands where it was arranged, one finger pans, two pinch to zoom, a double tap on empty space zooms in and a tap selects. Each person's view (zoom, place, selection) is remembered per map on the device, Fit frames a map only the first time or when pressed, and a link to a thought centres it ([#1553](https://github.com/ColdPhase/flux/issues/1553)).
