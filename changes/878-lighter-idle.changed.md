- An idle Flux uses about a seventh of the CPU (7.4% to 1.0% of a core on the measured stack) and a tenth of the database statements: health checks are small programs every 30 s, not a Node process every 3 s, and job queues wake the worker instead of being polled every 2 s. The application image is 216 MB, down from 500 MB ([#878](https://github.com/ColdPhase/flux/pull/878)).
- Operators: the default memory limits are now `FLUX_DB_MEMORY` 768m (new), `FLUX_API_MEMORY` 1536m and `FLUX_WORKER_MEMORY` 512m, 2.9 GiB for the base stack on a 4 GB host. Raise them in the settings file if your instance needs more. The health checks use `start_interval` (Docker Engine 25, Compose 2.20.2) ([#878](https://github.com/ColdPhase/flux/pull/878)).
