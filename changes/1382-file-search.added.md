- Search finds what is inside the files people send: the text of a PDF, a Word document (DOCX), Markdown, plain text and CSV/TSV is read once, when the message is sent (and for the files already there, in the background after the upgrade), in a sandboxed process that has no network, no files and no children and is limited in size, pages (the first 100), time (20 seconds) and memory; no OCR, and nothing in an encrypted space. A file is found like a message by whoever may read its space, and its row shows the matching text; agents find it with `flux_search` (`kind: "file"`) and read an excerpt of its text with the new `flux_read_file`. A removed file, message or space, and a lost grant, drop out at once ([#1382](https://github.com/ColdPhase/flux/issues/1382), C-63).
