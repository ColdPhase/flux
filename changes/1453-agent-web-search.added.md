- An agent on an Anthropic or OpenAI key searches the web with that provider's own search (`flux_web_search`, run by the Flux server with the key's hosted search, at most three searches a call, inside the key's daily budget), and lists what it searched; Claude Code and Codex use their own search. Gemini and OpenRouter keys and an endpoint of your own have no search in this release. `FLUX_WEB_READS=off` turns web search and page reading off ([#1441](https://github.com/ColdPhase/flux/issues/1441), [#1453](https://github.com/ColdPhase/flux/issues/1453)).
