- Flux is lighter on a modest server. An open Map or Wiki no longer reads its access rules four times a second: it listens for changes and looks only on activity or every two seconds when idle, and a cursor that has not moved no longer wakes the other editors. Two identical reads in flight at once share one request, the app reads the person and the workspaces together and then the projects and messages together, the video-call code is not downloaded ahead of time, and a session read no longer signs a token nobody reads ([#850](https://github.com/ColdPhase/flux/issues/850)).
- The performance check measures what a 2 vCPU host feels: a CPU-limited phase that holds every request to a 50 ms p95, the first-screen download, idle database statements and restart times, and a browser test counts the API requests of each move between places ([#850](https://github.com/ColdPhase/flux/issues/850)).
