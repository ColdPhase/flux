- An agent's web read no longer slows the server, however many links it read, and a page someone named opens: the link itself, the page a redirect sends it on to (a DOI's publisher, twitter.com to x.com), and the target of a pasted Google link. Flux's own wording and dates or times in what the agent read no longer block ordinary addresses, while a private link's id cannot ride in a form or search on the same site.
