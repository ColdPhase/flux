- Flux v0.2 does not upgrade a v0.1 instance, because v0.1 had no users: `./flux upgrade` refuses a database that v0.1 wrote before it asks, takes a backup or stops anything, the migration step (`./flux up`, `docker compose up`, a release install) refuses it before any migration file runs with `FLUX_V01_DATABASE`, and `./flux restore` refuses a v0.1 backup with or without `--migrate`. The message says to install v0.2 fresh (a new folder, or `./flux reset`) and that there is no import of v0.1 data; the upgrade guide and the v0.2 release notes say so too. An instance interrupted during its first install, before anybody signed up, is not refused ([#1176](https://github.com/ColdPhase/flux/issues/1176)).
