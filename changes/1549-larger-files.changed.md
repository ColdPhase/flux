- PDFs, scans, decks and other documents can be larger than 5 MiB: one file may be up to `FLUX_FILE_MAX_MIB` (an operator setting, 25 MiB by default, 1 to 1,024), streamed to and from the files volume like a video so the server's memory does not grow with it, and a message's files together up to four times that. The composer and the server say the limit in words ("Files can be up to 25 MB on this server"). A picture stays at 5 MiB, and so does every file of an encrypted space; your reverse proxy's body limit must allow the new size ([#1549](https://github.com/ColdPhase/flux/issues/1549)).
