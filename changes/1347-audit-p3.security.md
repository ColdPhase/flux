- A name with a direction-control or invisible character (U+202A-202E, U+2066-2069, U+200E/F, U+061C, U+200B, U+2060, U+FEFF) is refused when it is typed, for an agent, a workspace, a space and a person's sign-up or profile, and cleaned when it is read from the database, an identity provider or an OAuth client, so a name can no longer reorder the text beside it ([#1347](https://github.com/ColdPhase/flux/issues/1347)).
- A model list is read up to 1 MB (OpenRouter's up to 2 MB), and the API reads one list at a time for each person, so one session can no longer load the API with hundreds of listings of a large `/models` ([#1347](https://github.com/ColdPhase/flux/issues/1347)).
- A push subscription's endpoint held by another account moves to a new account only when the same browser keys come with it, so knowing a person's endpoint URL no longer takes their notifications ([#1347](https://github.com/ColdPhase/flux/issues/1347)).
- A call notice about the same place, and an invitation of the same person to it, is sent once in 5 minutes per member: a call that ends and starts again no longer tells the space again each time ([#1347](https://github.com/ColdPhase/flux/issues/1347)).
