- Tell an agent in its private chat "Every weekday at 9, summarise what changed in Garden" and it answers in plain words with what it prepared and one tap to turn it on. An agent's schedules are listed in its conversation, in one line in its header that opens the list, where you turn them on, pause, change, run now and delete them (with Undo); the agent's page shows the same list. Their results arrive in the agent's chat as one message each, and a run that fails or cannot start says so there: a schedule is never paused after failures. A schedule reads only web addresses you typed ([#858](https://github.com/ColdPhase/flux/issues/858)).
- The morning summary is a ready-made schedule on the agent's page, off until you turn it on ([#858](https://github.com/ColdPhase/flux/issues/858)).
