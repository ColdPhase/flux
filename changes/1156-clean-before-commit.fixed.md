- An agent's answer is checked before Flux saves it, so people's task changes in that space no longer wait for the check. A question to another agent is read only from the agent's own words, never from Flux's list of its web searches. The pages a run read are marked as they are read, so a run that ends without an answer lists a page it could open only through a person's link to that site as plain text, not as a link. Another bucket's page on Backblaze B2 opens, and its download hosts count each bucket as its own site ([#1156](https://github.com/ColdPhase/flux/issues/1156)).
