- Flux's pages and its service worker now carry a real Content-Security-Policy. Scripts run only from Flux's own files and the hashed inline ones (never `unsafe-inline` or `unsafe-eval`), the page connects only to its own origin, and plugins, frames, `<base>` and forms to other sites are refused, so a script an attacker managed to inject could neither run nor send anything out; styles may still be inline. The offline page's button no longer uses an inline handler ([#979](https://github.com/ColdPhase/flux/issues/979)).
