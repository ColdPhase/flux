- Encrypted workspaces (F-030, S2b): search and live editing of docs and maps work in an encrypted workspace while it is unlocked. Each API process keeps an in-memory search index of an unlocked workspace (never written to disk, dropped when the workspace locks). `FLUX_SEALED_SEARCH_MAX_BYTES` (default 256 MiB of estimated heap) bounds one workspace's index and `FLUX_SEALED_SEARCH_PROCESS_MAX_BYTES` (default a quarter of the API container's memory, at most 512 MiB) all of them in a process; a workspace that does not fit answers `sealedUnavailable` and idle indexes are evicted to make room. Live Wiki and map updates, snapshots and receipts are stored sealed, and locking a workspace closes its live rooms. Migration 0127. Encrypted workspaces cannot be created in a normal install yet ([#655](https://github.com/ColdPhase/flux/issues/655)).
