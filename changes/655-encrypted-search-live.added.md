- Encrypted workspaces (F-030, S2b): search and live editing of docs and maps work in an encrypted workspace while it is unlocked. Each API process keeps an in-memory search index of an unlocked workspace (never written to disk, dropped when the workspace locks); `FLUX_SEALED_SEARCH_MAX_BYTES` (default 256 MiB of text per workspace per process) bounds it, and a larger workspace answers `sealedUnavailable`. Live Wiki and map updates, snapshots and receipts are stored sealed, and locking a workspace closes its live rooms. Migration 0127. Encrypted workspaces cannot be created in a normal install yet ([#655](https://github.com/ColdPhase/flux/issues/655)).
