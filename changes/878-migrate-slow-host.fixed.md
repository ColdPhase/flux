- A fresh install on a slow disk or CPU no longer fails with `Query read timeout` in `migrate`: the migrator has its own long query bound instead of the API's 2 s. On v0.1.0 apply the first migration by hand, see [troubleshooting](docs/operations/troubleshooting.md#the-first-migration-on-a-slow-host-v010) ([#878](https://github.com/ColdPhase/flux/pull/878), [#846](https://github.com/ColdPhase/flux/issues/846)).
