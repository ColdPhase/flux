- Every agent runs in the agent runtime, and every API key runs in pi there (Anthropic, OpenAI, OpenRouter, Gemini, an OpenAI-compatible or a self-hosted endpoint), as a Claude or ChatGPT plan runs in Claude Code or Codex, with the same Flux tools. Each run has its own shell and files in a sandbox that lasts one run, and an agent attaches a file it made to its answer. The key never enters the sandbox: the worker's model gateway holds it, gives the run a token that lasts the run, and counts every request against the key's daily budget. The worker has no agent loop of its own any more. `./flux up` turns the runtime and API-key agents on where the host can run them, so AI works right after install ([#1441](https://github.com/ColdPhase/flux/issues/1441), [#1452](https://github.com/ColdPhase/flux/issues/1452), [#1444](https://github.com/ColdPhase/flux/issues/1444), [#1474](https://github.com/ColdPhase/flux/issues/1474), [#1451](https://github.com/ColdPhase/flux/issues/1451)).
