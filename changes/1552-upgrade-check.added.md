- `./flux upgrade --check` shows the plan of an upgrade and changes nothing: from which schema to which, the migrations by name, what each removes, and the size and rough time of the backup it will take. Every pull request that changes the database now proves that every released database upgrades to a schema equal to a fresh install's and keeps its data, and that nothing in the schema is unused; the release does the same on its real upgrade. A sequence left behind by an earlier redesign and two unused search kinds are removed ([#1552](https://github.com/ColdPhase/flux/issues/1552)).
