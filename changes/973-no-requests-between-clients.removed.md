- A local client or agent no longer sends a request to another one: the tools `flux_send_request`, `flux_claim_request`, `flux_defer_request`, `flux_decline_request`, `flux_resolve_request` and `flux_coordination_inbox`, the request cards and handoff packet in a task's thread, the cancel of a request, the limits on requests, and the recorded verdict of a review request are gone, with their API, tables and tests. Units stay (create, claim, renew, release, complete, transfer, decline), and a review is still never the run that made the work. The playbook is 1.14.0 and its request module is now "Hand off" ([#973](https://github.com/ColdPhase/flux/issues/973)).
