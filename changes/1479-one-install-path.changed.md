- Flux installs one way: download `flux.tar.gz`, `SHA256SUMS` and its signature, check, unpack and run `./flux up`. A release is the `flux` folder with the launcher and its Compose files; `./flux up` pulls the release's images pinned by digest and nothing is built on your machine. `./flux upgrade` moves to the next release and always checks the download against `SHA256SUMS` and its signature (cosign on the host, or the pinned cosign image through Docker) first, and refuses and changes nothing when it cannot. A v0.2.0 installation has nothing to carry into the release folder: install v0.2.1 fresh ([#1471](https://github.com/ColdPhase/flux/issues/1471), [#1479](https://github.com/ColdPhase/flux/issues/1479)).
