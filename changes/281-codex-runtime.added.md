- Your assistant can run on your own Codex: sign in with ChatGPT on Settings → Agents and AI (Flux shows the one-time code with *Copy and open ChatGPT*; an OpenAI API key or access token are under *Other ways to sign in*). Codex runs with every local tool switched off and Flux as its only tool server; a run that shows any other tool is stopped with nothing posted, and a ChatGPT plan limit pauses it with the reset time when Codex reports one ([#281](https://github.com/ColdPhase/flux/issues/281)).
