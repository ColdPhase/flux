- Flux can be installed from Settings → Appearance: the browser's own offer where there is one, "Share, then Add to Home Screen" on iPhone and iPad Safari, and nothing once it runs installed. An installed Flux opens at its start page with your session, a link reopens its project, and a closed app receives Web Push that opens the item. A refused notification permission is said in Settings and the in-app Inbox still works. An unsent phone draft survives applying an update, and the update prompt is a row above the shell, never over controls ([#756](https://github.com/ColdPhase/flux/pull/756), [#622](https://github.com/ColdPhase/flux/pull/622)).
