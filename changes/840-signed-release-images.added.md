- Release images are signed. The release workflow signs both image digests keylessly (cosign, Sigstore) after they pass the scan and the packaged install, `INSTALL.md` shows how to check the signature and the build provenance with `cosign verify` and `gh attestation verify` before you pull, and publishing a release now requires both signatures ([#840](https://github.com/ColdPhase/flux/issues/840)).
