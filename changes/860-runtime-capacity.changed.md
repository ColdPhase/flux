- The agent runtime has no fixed number of people: one runtime serves everyone with Connect AI, each person under their own user id. How many agents run at once follows from memory, about 2 on 4 GB, and the others wait with "Waiting for room on the server". `FLUX_RUNTIME_MAX_RUNS` changes the number ([#860](https://github.com/ColdPhase/flux/issues/860)).
- A host that does not meet a runtime requirement, such as `kernel.yama.ptrace_scope=0`, stops the runtime with one clear message and the fix. There is no restart loop, and `./flux up` fails instead of reporting a healthy Flux ([#860](https://github.com/ColdPhase/flux/issues/860)).
