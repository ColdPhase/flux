- The media server of calls has limits like every other service: 512 MB of memory and swap and one CPU (`FLUX_LIVEKIT_MEMORY` and `FLUX_LIVEKIT_CPUS`), at most 512 processes, no capabilities, no new privileges and a read-only root, so a call cannot take memory from the database and the keyring. A 16-person call measured 75 to 86 MB and under 10 % of a core ([#1558](https://github.com/ColdPhase/flux/issues/1558)).
