- Co-work with your own agent: Connect and Agents offer Claude Code's `/mcp__flux__start_work` and `/mcp__flux__resume_work` and Codex's `./flux cowork start|resume`, which resume the same project and thread from a saved checkpoint. A person who may stop an agent can also pause it; it pauses at its next safe point and can still save a checkpoint. Events of a linked GitHub pull request reach the connection whose agent holds the task, and an agent can link the pull request it produced to that task ([#616](https://github.com/ColdPhase/flux/pull/616), [#649](https://github.com/ColdPhase/flux/pull/649), [#751](https://github.com/ColdPhase/flux/pull/751), [#760](https://github.com/ColdPhase/flux/pull/760)).
