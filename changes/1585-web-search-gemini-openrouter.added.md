- An agent on a Gemini or OpenRouter key searches the web too: Gemini with Google Search grounding, OpenRouter with its web search (Exa), through `flux_web_search`, inside the key's daily budget at the provider's search price, and lists what it searched. An endpoint of your own still has no web search, and its agent says so. A Gemini key says in Settings › AI that Google’s Gemini API terms apply to its search, which are yours to follow. `FLUX_WEB_READS=off` turns it off ([#1585](https://github.com/ColdPhase/flux/issues/1585)).
