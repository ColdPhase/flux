- Accounts come only from a link. The first `./flux up` prints a setup link, and only it makes the first account, the company's owner (a new Flux opens on Set up Flux); everyone else creates an account from an invite link or signs in with single sign-on, and nobody can sign up alone, so a server on the internet cannot be claimed or filled with accounts by strangers. A forgotten password is a reset link, with or without email: an owner or admin makes one next to the person in Settings › Company, `./flux reset-link <email>` prints one for any account, and Forgot password mails one when the server has email. A link works once, for one hour, a newer one stops it, and using it signs the person out everywhere ([#1471](https://github.com/ColdPhase/flux/issues/1471), [#1484](https://github.com/ColdPhase/flux/issues/1484)).
