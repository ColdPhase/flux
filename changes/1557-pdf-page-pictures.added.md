- An agent sees the pages of a PDF that has no text (a scan, an exported mind map, slides saved as pictures): the worker keeps a picture of each of the first 10 pages and `flux_read_file` gives them to an agent whose model sees pictures, while an agent whose model does not is told the PDF has no text and cannot be read. The file's row reads "PDF · 1 page · no text" and its preview says "No text in this PDF (scan or picture)"; PDFs of v0.2.1 that were read and had no text are read again in the background after the upgrade ([#1557](https://github.com/ColdPhase/flux/issues/1557)).
