- Releasing a person from the agent runtime now removes what their program left anywhere in the shared `/tmp` that their user id can reach and list, also a directory of theirs inside a directory of someone else's and a tree deeper than `PATH_MAX`, which `rm` cannot take (a file in a directory of someone else's that can be entered but not read is not found); their `/data` directory is removed by a walk that follows no link, even one another person swaps in while it runs; the same tree in their own directory no longer keeps the release open for good. A release that is asked again does not sign them out a second time, and `agent-runtime.md` has a section for a release that stays open ([#915](https://github.com/ColdPhase/flux/issues/915)).
- A key's budget is checked against the model the assistant ends up on even when the model is changed at the same moment, and the day of a key whose clocks go back at midnight (Havana) begins at the first midnight ([#915](https://github.com/ColdPhase/flux/issues/915)).
