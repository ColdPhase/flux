- A job that holds a database session lock (the agent runtime reconciler, a live-session transition, a live access revocation) now stops at its next step when the lock's connection dies, instead of carrying on without the lock; the API start no longer logs Fastify's FSTWRN004 or `pg`'s deprecation of overlapping statements on one connection; a refresh token used by several requests at once makes one new token pair; and the database outage check proves the worker runs a job after the database returns ([#916](https://github.com/ColdPhase/flux/issues/916)).
