- A task someone or an agent gives you reaches your Inbox as a "Task" item, while it is unread and still yours and not started, and opening the task reads it. Done on it finishes the task, and Done on your own blocked task finishes that one too, each with an Undo that puts the task back (to open, or to Blocked with what it waited for); for the person a task waits for, Done lets the task continue. The line under the Inbox, "2 for later · 4 done today", opens its lists: what Not now put off, with when it comes back and Bring back now, and what was marked done in the last 24 hours, with Put back ([#1424](https://github.com/ColdPhase/flux/issues/1424) decisions C and E, 2026-11-15, round 8).
